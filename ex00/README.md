# Personal Portfolio - Project 04

## Description
A responsive personal portfolio website created using
HTML, CSS, and JavaScript.

## Features
- Responsive navigation bar
- About Me section with profile picture
- Skills section
- Projects showcase (Project 00 - Project 03)
- Hobbies section
- Contact form with required field validation
- Interactive Light/Dark theme switcher

## Technologies
- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Media Queries

## How to Run
1. Open the ex00 directory.
2. Open index.html in a web browser.
3. Use the navigation links to explore the website.
4. Click the theme button to switch between Light and Dark Mode.
